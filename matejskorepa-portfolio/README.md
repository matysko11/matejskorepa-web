# Matěj Skořepa - profesionální portfolio

Hotová statická verze webu je v této složce.

## Spuštění

Otevři `index.html` v prohlížeči, nebo složku nahraj na GitHub Pages.

## Obsah

- `index.html` - struktura webu
- `styles.css` - grafika a responzivní vzhled
- `app.js` - loader, animace, lightbox, filtrování, mobilní menu a kopírování e-mailu
- `assets/images` - optimalizované obrázky z portfolia
- `assets/docs` - CV, motivační dopis, osvědčení, logo manuál a video
- `assets/thumbs` - náhledy dokumentů
- Maturitní projekt je doplněný jako PDF dokumentace a plakátový obrázek `model-skoly-3d.jpg`

Video je ponechané jako `.mkv` ke stažení, protože tento formát se v prohlížečích nemusí přehrát spolehlivě přímo na stránce.
